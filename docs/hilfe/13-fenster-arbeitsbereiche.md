# Reiter, geteilte Ansicht und Arbeitsbereiche

## Reiter

| Aktion | Tastenkürzel |
| ------ | ------------ |
| Neuer Reiter | Strg+T |
| Neues Fenster | Strg+N |

Das Menü **Gehe zu ▸ Reiter** listet alle Reiter des Fensters; ein Klick wechselt dorthin.

## Geteilte Ansicht

Zeigt zwei oder mehr Ordner nebeneinander – ideal zum Kopieren und Vergleichen. Alle Befehle stehen unter **Ansicht ▸ Geteilte Ansicht**:

![Das Menü Ansicht ▸ Geteilte Ansicht](bilder/menue-geteilte-ansicht.png)

| Eintrag | Wirkung |
| ------- | ------- |
| Zusätzliche Leiste (F3) | fügt einen weiteren Bereich hinzu |
| Ansicht horizontal teilen (Umschalt+F3) | teilt waagerecht statt senkrecht |
| Bereich duplizieren | legt eine Kopie des aktiven Bereichs an |
| Bereich maximieren | der aktive Bereich füllt das Fenster |
| Bereich schließen | entfernt den aktiven Bereich |

Es sind bis zu **vier Bereiche** möglich. Jeder hat seine eigene Adressleiste und seinen eigenen Ordner; der Bereich, in dem Sie zuletzt geklickt haben, ist aktiv.

![Vier Bereiche mit verschiedenen Ordnern](bilder/ansicht-vier-bereiche.png)

> **Tipp:** Ziehen Sie Dateien mit der Maus von einem Bereich in den anderen, oder kopieren Sie mit Strg+C im einen und Strg+V im anderen.

## Arbeitsbereiche

Ein **Arbeitsbereich** merkt sich Ihre Fensteranordnung: Reiter, Teilung, Fenstergröße und die geöffneten Panels. So holen Sie ein Arbeitsumfeld mit einem Klick zurück.

![Das Menü Datei ▸ Arbeitsbereiche](bilder/menue-arbeitsbereiche.png)

1. Richten Sie das Fenster so ein, wie Sie es brauchen.
2. **Datei ▸ Arbeitsbereiche ▸ Speichern …**
3. Geben Sie einen Namen ein und drücken Sie **Speichern**.

![Das Panel Arbeitsbereiche mit einem gespeicherten Arbeitsbereich](bilder/panel-arbeitsbereiche.png)

| Schaltfläche | Wirkung |
| ------------ | ------- |
| Laden | stellt den gewählten Arbeitsbereich wieder her |
| Duplizieren | legt eine Kopie unter neuem Namen an |
| Löschen | entfernt den gewählten Arbeitsbereich |

Die Spalte **Inhalt** nennt kurz, was gespeichert ist (z. B. „1 + 1 Reiter, geteilt“).

## Letzte Sitzung

Beim Beenden merkt sich Nolphin außerdem die **letzte Sitzung**. Ob sie beim nächsten Start wiederhergestellt wird, legen Sie in den Einstellungen (Verhalten: „Reiter des letzten Fensters beim Start wiederherstellen“) fest.
