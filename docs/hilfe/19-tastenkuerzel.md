# Tastenkürzel

Die vollständige Liste zeigt **Hilfe ▸ Tastenkombinationen** (Strg+F1).

## Fenster und Panels

| Kürzel | Wirkung |
| ------ | ------- |
| F1 | diese Hilfe |
| F11 | Arbeitsbereich ein/aus |
| F4 | Terminal |
| F3 | zusätzliche Leiste (geteilte Ansicht) |
| Umschalt+F3 | Ansicht horizontal teilen |
| Strg+F | Suche |
| Strg+L | Adresse eingeben |
| Alt+Eingabe | Eigenschaften |

## Dateien

| Kürzel | Wirkung |
| ------ | ------- |
| Strg+T | neuer Reiter |
| Strg+N | neues Fenster |
| Umschalt+Strg+N | neuer Ordner |
| Strg+C / Strg+X / Strg+V | kopieren / ausschneiden / einfügen |
| F2 | umbenennen |
| Strg+A | alles auswählen |
| Strg+S | nach Muster auswählen |
| Umschalt+Strg+I | Auswahl umkehren |
| Strg+H | versteckte Dateien ein/aus |

## Ansicht

| Kürzel | Wirkung |
| ------ | ------- |
| Strg+1 / 2 / 3 / 4 | Symbol-, Listen-, Kompakt-, Galerieansicht |
| Strg++ / Strg+- / Strg+0 | größer / kleiner / normal |
| Strg+R | aktualisieren |

## Navigation

| Kürzel | Wirkung |
| ------ | ------- |
| Alt+Hoch | übergeordneter Ordner |
| Alt+Links / Alt+Rechts | zurück / vorwärts |
| Alt+Pos1 | persönlicher Ordner |
| Strg+D | Lesezeichen hinzufügen |
