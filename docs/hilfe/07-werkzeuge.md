# Werkzeuge im Überblick

Alle Werkzeuge liegen im Menü **Bearbeiten ▸ Werkzeuge**.

![Menü Bearbeiten ▸ Werkzeuge](bilder/menue-werkzeuge.png)

| Werkzeug | Wozu | Thema |
| -------- | ---- | ----- |
| Ordner vergleichen / synchronisieren … | zwei Ordner abgleichen | [Synchronisation](hilfe:synchronisation) |
| Regeln anwenden … | Dateien nach Bedingungen verschieben oder bearbeiten | [Regeln](hilfe:regeln) |
| Stapelverarbeitung … | die aktuelle Auswahl mit einer Aktion oder einem Befehl bearbeiten | [Regeln](hilfe:regeln) |
| Duplikate finden … | gleiche Dateien aufspüren | [Duplikate](hilfe:duplikate) |
| Versionen ▸ | Stände einer Datei sichern und wiederherstellen | [Versionen](hilfe:versionen) |

## Das Prinzip: erst Vorschau, dann Änderung

Jedes Werkzeug zeigt **zuerst, was passieren würde**. Verändert wird erst, wenn Sie ausdrücklich **Anwenden**, **Synchronisieren** oder **In den Papierkorb** wählen. Gelöscht wird nie endgültig und nie ohne Rückfrage; wo es um Dateien geht, landen sie im Papierkorb.

> **Tipp:** Arbeiten Sie sich mit der Vorschau vor. Sie kostet nichts und zeigt Fehler in der Bedingung sofort.
