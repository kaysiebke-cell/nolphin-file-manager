# Duplikate finden

**Bearbeiten ▸ Werkzeuge ▸ Duplikate finden …** sucht in einem Ordner samt Unterordnern nach Dateien, die doppelt vorliegen.

![Duplikate-Panel mit einer Gruppe gleicher Dateien](bilder/panel-duplikate.png)

## Vergleichsart

| Art | Wann sinnvoll |
| --- | ------------- |
| Gleicher Inhalt (Prüfsumme) | zuverlässig; verglichen wird die SHA-256-Prüfsumme (Standard) |
| Gleicher Name | schnell, aber ungenau |
| Gleiche Größe | als Vorfilter bei großen Beständen |

„Versteckte Dateien“ schaltet die Suche in verborgenen Dateien ein. Mit **Abbrechen** stoppen Sie eine laufende Suche.

## Aufräumen

1. **Suchen.** Gefundene Dateien erscheinen **in Gruppen** („2 Dateien – je 100 Bytes“).
2. **Alle außer der ersten markieren** hakt in jeder Gruppe alle bis auf eine Datei an – so bleibt in jeder Gruppe ein Original.
3. Prüfen Sie die Haken von Hand und ändern Sie sie bei Bedarf.
4. **Markierte in den Papierkorb**.

Unter der Liste steht, wie viele Gruppen es gibt und wie viel Platz sich gewinnen lässt.

> **Sicherheit:** Gelöscht wird **nur in den Papierkorb** und erst nach Ihrer Bestätigung. Nolphin entscheidet nie selbst, welche Kopie die „richtige“ ist.
