# Einstellungen

**Bearbeiten ▸ Einstellungen** öffnet die Einstellungen im Hauptbereich, wie diese Hilfe. **Esc** oder „Schließen“ führt zurück.

![Einstellungen: Seite „Verhalten“](bilder/einstellungen-verhalten.png)

## Die Seiten

| Seite | Was Sie dort einstellen |
| ----- | ----------------------- |
| Ansichten | Standardansicht, Sortierung, Zoomstufen für Symbol-, Kompakt- und Listenansicht |
| Verhalten | Klickverhalten, Papierkorb, Datenträger, Umbenennen mehrerer Elemente, Sitzung wiederherstellen |
| Anzeige | welche Angaben unter den Symbolen und in der Statusleiste erscheinen |
| Listenspalten | welche Spalten die Listenansicht zeigt und in welcher Reihenfolge |
| Vorschau | wann Vorschaubilder und Vorschauen erzeugt werden |
| Werkzeugleiste | welche Knöpfe die Werkzeugleiste zeigt |
| Kontextmenü | welche Einträge im Kontextmenü stehen |
| Dokumentvorlagen | Vorlagen für „Neues Dokument anlegen“ |
| Module | Aktionen und Erweiterungen ein- und ausschalten |

## Exportieren, Importieren, Zurücksetzen

Am unteren Rand jeder Seite:

| Knopf | Wirkung |
| ----- | ------- |
| Exportieren … | schreibt **alle** Einstellungen in eine Datei |
| Importieren … | liest eine solche Datei wieder ein |
| Zurücksetzen … | stellt die Standardwerte wieder her |

> **Tipp:** Exportieren Sie Ihre Einstellungen vor größeren Änderungen. So können Sie sie auf einen anderen Rechner übertragen oder zurückholen.

## Module und der Layout-Editor

Die Seite **Module** listet **Aktionen** und **Erweiterungen**. Mit den Häkchen schalten Sie einzelne Einträge ein oder aus, **Alle aktivieren / Alle deaktivieren** wirken auf die ganze Liste.

![Einstellungen: Seite „Module“](bilder/einstellungen-aktionen.png)

**Anordnung bearbeiten** öffnet den **Layout-Editor**. Dort bestimmen Sie Reihenfolge, Untermenüs, Trennlinien und Tastenkürzel der Aktionen in den Menüs.

![Der Layout-Editor für Aktionen](bilder/aktionen-layout-editor.png)
