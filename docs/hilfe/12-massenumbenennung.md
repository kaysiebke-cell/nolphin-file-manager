# Massenumbenennung

Mehrere Dateien auf einmal umbenennen – mit Vorschau, bevor etwas geschieht.

1. Dateien markieren.
2. **Bearbeiten ▸ Massenumbenennung …**

![Massenumbenennung mit Suchen, Ersetzen und Nummerierung](bilder/panel-massenumbenennung.png)

## Einstellungen

| Feld | Wirkung |
| ---- | ------- |
| Suchen / Ersetzen durch | ersetzt Text im Namen; leer lassen, wenn nur nummeriert werden soll |
| Groß-/Kleinschreibung beim Suchen beachten | genauer oder großzügiger suchen |
| Nummerierung hinzufügen | stellt eine laufende Nummer **vor** oder **nach** den Namen |
| Start bei / Stellen | erste Nummer und Anzahl der Ziffern (z. B. `01`) |
| Groß-/Kleinschreibung | Namen in Groß- oder Kleinbuchstaben wandeln |

Die Spalte **Neuer Name** aktualisiert sich bei jeder Eingabe. Erst **Anwenden** benennt tatsächlich um.

## Beispiel

*Aus `c.txt`, `c.txt.bak`, `d.png` soll `01_bericht.txt`, … werden:*

- Suchen: `c` – Ersetzen durch: `bericht`
- Nummerierung hinzufügen, Position „Vor dem Namen“, Start 1, 2 Stellen

> **Hinweis:** Das Umbenennen lässt sich über **Bearbeiten ▸ Rückgängig** wieder zurücknehmen.
